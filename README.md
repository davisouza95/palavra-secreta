# Palavra Secreta

Site estático do jogo Palavra Secreta.

## Publicar com GitHub Pages

1. Crie um repositório público no GitHub.
2. Envie `docs/index.html` e este README para a branch `main`.
3. Em Settings → Pages, escolha `Deploy from a branch`, branch `main` e pasta `/docs`.
4. Salve e aguarde o endereço do site aparecer na tela de Pages.

As respostas estão incluídas no JavaScript desta versão de demonstração e poderão ser vistas no código-fonte.
